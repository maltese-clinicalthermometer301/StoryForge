## 🧩 What StoryForge does

StoryForge helps you turn a story idea into a structured output. It follows a clear flow:

- Start with a short idea or premise
- Confirm the synopsis before work continues
- Generate a script for the story
- Turn the script into a storyboard
- Review the output with an evaluation loop
- Improve the result based on the review

This makes it easier to move from a rough idea to a more complete story plan.

## ✍️ How to use it

Use StoryForge when you want a guided story pipeline.

Good inputs include:

- A short story idea
- A film scene
- A game cutscene
- A comic chapter
- A video storyboard
- A character setup with a goal and conflict

Try this shape for your prompt:

- Who is the main character?
- What do they want?
- What stops them?
- What changes by the end?
- What should the scene feel like?

This gives the runtime enough detail to build a cleaner result.

## 🎛️ Typical workflow

A simple workflow looks like this:

3. Generate the script
4. Review the scene structure

Use one idea per run. That keeps the output focused.
